# Charlie Pelle | Fullstack Developer Portfolio

Personal portfolio for Charlie Pelle, Fullstack Developer and BS Information Systems graduate from Bago City College, Philippines. Featuring civic systems, university platforms, and emergency networks.

- **GitHub Repository**: [https://github.com/ItsChaBTW/Pelle-Portfolio](https://github.com/ItsChaBTW/Pelle-Portfolio)
- **Live Preview / Dev**: `http://localhost:5173/`

## Stack

- **Framework**: Vite 6, React 19, TypeScript
- **Styling**: Modern CSS Custom Properties, Responsive BEM
- **3D & Animation**: Three.js (interactive 3D card carousel & contour shaders), GSAP, Lenis Smooth Scroll
- **Routing & Icons**: React Router 7, Phosphor Icons

## Featured Systems

1. **Bagotizen Card Online Pre-Enrollment** — Pre-enrollment platform for 850+ Iskolar Bago beneficiaries with GCash integration and QR reference codes.
2. **BYEA Tabulation 2026** — Jury judging and real-time score tabulation platform for Bagonhon Youth for Excellence Awards 2026.
3. **Web-Based Event Management System (EMS)** — QR-powered event attendance and competition tabulation.
4. **ITech Student Clearance System** — University academic clearance and document request tracking across Library, Finance, and Registrar.
5. **City of Bago Iskolar Portal** — Official municipal scholarship portal (BAGO.GOV).
6. **THYNK Disaster Response Network** — Rapid disaster coordination platform built with C# ASP.NET Core & SQL Server.
7. **Busay Health Center Community Portal** — Clinic appointment booking and patient records platform.

## Development

```bash
npm install        # Install dependencies
npm run dev        # Run local dev server (http://localhost:5173)
npm run build      # Compile production build to dist/
npm run preview    # Preview compiled dist bundle
npm run typecheck  # Run TypeScript verification
```
